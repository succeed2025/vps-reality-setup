# 使用建议与维护

> 以下是**经验之谈，不是官方标准**，目的是降低自建节点 IP 被盯上的概率。

## 用量建议

| 项目 | 建议 |
|---|---|
| 每日流量 | ≤ 5 GB |
| 每月流量 | ≤ 100 GB |
| 视频清晰度 | 720p / 1080p 即可，避免长期 4K |
| 单次连续使用 | 控制在 2–3 小时以内，中间断开歇一会儿 |
| 大流量（长视频、下载、更新游戏） | 用机场，不要走自建节点 |
| 分享 | **绝不分享节点**，一人一节点 |
| 敏感时期 | 重大会议/纪念日前后少用、慢用，必要时暂停 |

服务器上已屏蔽 BT 下载，并屏蔽通过节点访问国内 IP（`geoip:cn`）和内网地址。

## 监控思路

每天 **两次**（例如早晚各一次）从国内测可达性：

```bash
bash scripts/check-cn.sh <VPS_IP> <SSH端口>
```

可以交给 AI 助手做成定时任务，发现 TCP 443 全部不通时提醒你。
服务器侧快速自检：

```bash
systemctl is-active xray
tail -n 50 /var/log/xray/error.log
```

## 出问题时的处理顺序（从便宜到贵）

1. **先查自己**：客户端是否选对节点、有没有同时开别的代理、SwitchyOmega、本地网络/公司网络是否正常、换手机流量试试。
2. **重启 Xray**（🌐）：`systemctl restart xray && systemctl status xray --no-pager`
3. **换端口 / 换 SNI**：改 `/usr/local/etc/xray/config.json` 的 `port` 或 `dest`/`serverNames`（记得 `ufw allow 新端口/tcp`），或重跑 `bash install.sh --sni <新站点>`，然后更新客户端。
4. **换协议**：如 REALITY 整体被针对，再考虑其他方案。
5. **换 IP（最后手段，通常要花钱）**：找服务商换 IP 或开新机。**任何付费操作前先确认**，不要让助手自动下单/续费/重装。
